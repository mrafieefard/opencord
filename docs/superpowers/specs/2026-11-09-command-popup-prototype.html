Command popup prototype

The desktop popup and the phone list from milestone 1.5, in the app's real colours and sizes. Both respond: click into a field and type /, or use the controls to try the numbers still open.

Desktop

#general
  • ↑ ↓ every row across groups · Ctrl+↑ ↓ jump a group · Enter or Tab pick · Esc close
  • /roll from Dice Bot answers · /ticket thinks, then answers · /close thinks, then doesn't answer · /queue is only for you
  • /play then two letters shows songs in the same popup · @ # : use it too, without the rail · Esc on /roll, then Enter, shows the "pick one" reply
